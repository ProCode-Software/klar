# Klar AST

The `ast` package defines abstract syntax tree (AST) nodes defining all syntax features in the Klar language. AST nodes are generated by the [parser](../parser/README.md) based on the types of tokens from the [lexer](../lexer/README.md) and their order. The AST is later used for analysis, type checking, and optimization.

For example, the following Klar code:

```klar
msg := "Hello World!"
```

Produces the following AST:

```go
&ast.VariableDeclaration{
  BaseNode: ast.BaseNode{
    Range: ranges.Range{
      Start: lexer.Position{1:1},
      End: lexer.Position{1:22},
    },
  },
  Variables: []ast.Assignable{
    &ast.Symbol{
      BaseNode: ast.BaseNode{
        Range: ranges.Range{
          Start: lexer.Position{1:1},
          End: lexer.Position{1:4},
        },
      },
      Identifier: "msg",
    },
  },
  Values: []ast.Expression{
    &ast.StringLiteral{
      BaseNode: ast.BaseNode{
        Range: ranges.Range{
          Start: lexer.Position{1:8},
          End: lexer.Position{1:22},
        },
      },
      QuoteStyle: 34,
      Content: "Hello World!",
      Fragments: []ast.StringFragment{
        lexer.TextFragment{
          Source: "Hello World!",
          LineOffset: 0,
        },
      },
    },
  },
  ExplicitType: nil,
}
```

You can print an AST like the one above by calling `litter.Dump(ast)` from the [`litter`](github.com/sanity-io/litter) package.

## The `Program` node

Klar files are parsed into a single root node `ast.Program`. This contains the top-level statements in the file, and all the comments in the file in a single slice.

```go
// A Program is a parsed Klar file. Body contains the parsed statements in the program,
// and all comments are moved to Comments.
type Program struct {
	BaseNode
	Body     []Statement
	Comments []*Comment
}
```

## Location Info

All AST nodes contain information about their range in the file, which is used for error reporting and the LSP. These are accessible through the `Range` field on most nodes, or `GetRange()` on all nodes. Ranges have type [`ranges.Range`](../ranges/ranges.go).

## Interfaces

The `ast` package declares interfaces such as:

- `Node`, implemented by all nodes. Implementations are pointers to structs.
- `Expression`
- `Statement`
- `Type` for nodes used in type annotations
- `Assignable` for expressions that are valid on the left-hand side of an assignment
- `Destructurable` for `Assignable` nodes that can be used in a `:=` variable declaration

## Node Equality

All nodes contain an `Equal` method that structurally compares them to another node. Comparison via `Equal` disregards range information and pointer references.

## Other Utilities

- [`PrimitiveTypeName`](./ast.go) defines the primitive named types in Klar. When parsing a `TypeAlias`, the identifier is checked in `PrimitiveTypeMap` for a matching primitive type. If there is a match, the `TypeAlias` is instead parsed as a `PrimitiveType`.
- [`Identifier`](./extra.go) defines an identifier. It is used instead of `Symbol` to preserve the identifier's length.
- [`Operator`](./extra.go) represents an operator like `+` or `!!`. It stores the operator as a lexer token type and the start position where it was used.
